# Plugin-Vertrag

Ein Spielemodul beschreibt eindeutig seine ID, seinen Namen, die Altersgruppe, erlaubte Einstellungen, benötigte Inhaltstypen und seine Tests. Die Plattform kann dadurch Spiele unabhängig verwalten, aktivieren und deaktivieren.

- Jede technische Spiel-ID ist stabil und besteht aus Kleinbuchstaben, Ziffern und Unterstrichen.
- Einstellungen werden vom Server validiert. Browser-Daten entscheiden nie über Rollen, Veröffentlichung oder Bezahlung.
- Ein Spiel darf nur seine fest zugeordneten API-Pfade aufrufen.
- Erfolgsbildschirme verwenden das gemeinsame, kindgerechte Abschlussmuster.
- Touch muss vollständig ohne Hover funktionieren.

Siehe das [Manifest-Beispiel](codebeispiele/spielmanifest.md). Die konkrete private Vorlage wird erst nach einer Werkstattfreigabe bereitgestellt.
