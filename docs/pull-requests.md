# Pull Requests

Technische Änderungen werden über Pull Requests besprochen. Ein Pull Request beschreibt Ziel, betroffene Spiel-ID, Tests, Medien-/Lizenzlage und bekannte Risiken. Keine Secrets, Zugangsdaten, persönlichen Testkonten oder Produktionsdaten in Beschreibungen, Commits oder Screenshots.

Nur ein Admin entscheidet über die Übernahme in die Plattform oder einen Staging-Build. Ein Merge veröffentlicht kein Spiel automatisch.
