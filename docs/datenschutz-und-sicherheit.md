# Datenschutz und Sicherheit

Ein Spiel verarbeitet nur Daten, die für seine Funktion nötig sind. Keine Passwörter, Zahlungsdaten, Session-Tokens oder vollständigen Profile in Logs, Tests oder Repositories speichern.

Berechtigungen, Abonnements, Freigaben und Moderationsrechte werden ausschließlich serverseitig entschieden. Alle Eingaben werden serverseitig validiert; Datenbankabfragen verwenden gebundene Parameter. Sicherheitslücken werden über den geschützten Meldeweg gemeldet, nicht als öffentliche Diskussion veröffentlicht.
