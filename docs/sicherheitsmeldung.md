# Sicherheitsmeldung

Bitte veröffentliche Sicherheitslücken nicht als Issue und teile keine personenbezogenen Daten. Melde sie über den geschützten Entwicklerbereich mit einer kurzen Reproduktion, dem betroffenen Bereich und einer Kontaktmöglichkeit. Die Plattform bestätigt den Eingang und koordiniert die Behebung vertraulich.
