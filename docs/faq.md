# FAQ

**Kann ich ein Spiel direkt hochladen?** Nein. Repository und Code werden erst nach Prüfung in einen Staging-Build übernommen.

**Kann ich ein eigenes Repository anlegen?** Ja, nach Freischaltung im Entwicklerbereich. Es bleibt privat, bis eine Freigabe etwas anderes vorsieht.

**Können Moderatoren veröffentlichen?** Nein. Sie testen und geben Empfehlungen ab. Die finale Entscheidung liegt bei Admins.

**Warum gibt es keine öffentlichen Issues?** Fehler- und Sicherheitsvorgänge können interne Technik oder personenbezogene Daten berühren. Sie werden daher geschützt bearbeitet.
